## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. ৩টি বিশেষায়িত রিডিং মোড (Reading Modes)
- **পদ দ্বারা পদ (Line-by-line Study Mode)**: প্রতিটি আয়াতের আরবি পাঠের নিচে নির্বাচিত বাংলা অনুবাদ। মাউস নিলে স্পিচ-বাবল টুলটিপে শব্দের অর্থ ভেসে ওঠে।
- **পড়া (Mushaf Reading Mode)**: অনুবাদমুক্ত খাঁটি নূরানী/উসমানী মুসহাফ প্রবাহ। সূরার অলঙ্কৃত ফ্রেম এবং বিসমিল্লাহ সহ একটানা তিলাওয়াত পাঠের অভিজ্ঞতা।
- **হিফজ (Hifz / Memorization Mode)**: আয়াত বারবার পুনরাবৃত্তি (1x, 3x, 5x, 10x) এবং অনুবাদ আড়াল করে মুখস্থ চর্চার বিশেষ মোড।

### ২. নির্ভরযোগ্য বাংলা অনুবাদকসমূহ (Authentic Bangla Translations)
- **ড. মজিবুর রহমান** (দারুসসালাম পাবলিকেশন - Darussalaam)
- **ড. আবু বকর মুহাম্মাদ যাকারিয়া** (বাদশাহ ফাহাদ কুরআন কমপ্লেক্স, মদীনা)
- **মুফতি তাকী উসমানী / তায়সিরুল কুরআন** (তাওহীদ পাবলিকেশন্স)
- **Saheeh International** (ইংরেজি অনুবাদ)
- **সবগুলো অনুবাদ একসাথে** প্রদর্শন করার সুবিধা

### ৩. আয়াত-টু-আয়াত বিস্তারিত তাফসীর ও পাঠ (In-depth Tafsir & Insights)
- **📖 তাফসীর (Live Tafsir)**: লাইভ এপিআই মারফত তাফসীর ইবনে কাসীর ও তাফসীর ড. আবু বকর যাকারিয়া এক ক্লিকেই পড়ার সুবিধা।
- **🎓 পাঠ (Lessons & Guidance)**: প্রতিটি আয়াতের আকিদাগত শিক্ষা, নৈতিক বিধান ও বাস্তব জীবনের দিকনির্দেশনা।
- **💬 প্রতিফলন (Tadabbur & Personal Notes)**: গভীর তাদাব্বুর ভাবনা এবং ব্যক্তিগত অনুভূতি লিখে সংরক্ষণের জন্য লোকালস্টোরেজ সমৃদ্ধ নোটপ্যাড।
- **📘 হাদিস (Authentic Hadith)**: সংশ্লিষ্ট আয়াতের ফযীলত ও শানে নুযূল সম্বলিত বিশুদ্ধ হাদিস (বুখারী, মুসলিম ইত্যাদি থেকে)।

### ৪. বিশ্ববিখ্যাত ক্বারীদের অডিও তিলাওয়াত (Audio Recitations)
- **সম্পূর্ণ সূরা একটানা তিলাওয়াত**: কোনো বিরতি বা বাফারিং ছাড়াই পূর্ণ সূরা অবিচ্ছিন্নভাবে শোনার সুবিধা।
- **নির্দিষ্ট আয়াতভিত্তিক তিলাওয়াত**: শুধুমাত্র কাঙ্ক্ষিত আয়াতটি এককভাবে শোনার প্লেয়ার।
- **ক্বারীবৃন্দ**: মিশারী রশিদ আল-আফাসী, আব্দুল বাসেত আব্দুস সামাদ, মাহের আল-মুয়াইক্বলী, সা'দ আল-গামদী, মুহাম্মদ সিদ্দিক আল-মিনশাবী, আলী আল-হুজাইফী।

### ৫. প্রিমিয়াম ডিজাইন ও ইউজার ইন্টারফেস (UI/UX)
- ডার্ক স্লেট ও গোল্ডেন অ্যাম্বার কালার স্কিম।
- স্ক্রল করলেও শীর্ষ নেভিগেশন বার পিন্ড (Sticky) হয়ে স্ক্রিনের উপরে অবস্থান করে।
- ডান পাশ থেকে মসৃণ অ্যানিমেশনে ভেসে ওঠা সম্পূর্ণ কাস্টমাইজেবল **সেটিংস ড্রয়ার** (আরবি লিপি, ফন্ট স্কেল, লাইন ফরম্যাট ও অনুবাদক নির্বাচন)।
- বুকমার্ক ম্যানেজমেন্ট ও একাধিক ব্যাকগ্রাউন্ড থিম (Dark, Emerald, Sepia)।

## 🚀 ইনস্টলেশন ও লোকাল সেটআপ (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/EHRAHIN/Quran-pori.git
cd Quran-pori
```

### ২. ব্যাকএন্ড ডিপেনডেন্সি ইনস্টল করুন:
```bash
cd server
npm install
```

### ৩. সার্ভার এনভায়রনমেন্ট কনফিগার করুন:
`server/` ডিরেক্টরিতে `.env` ফাইল তৈরি করুন:
```env
PORT=5050
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.symslyn.mongodb.net/quran_app?retryWrites=true&w=majority
NODE_ENV=development
CLIENT_URL=http://localhost:5173
```

### ৪. ফ্রন্টএন্ড ডিপেনডেন্সি ইনস্টল করুন:
```bash
cd ../client
npm install
```

### ৫. অ্যাপ্লিকেশনটি রান করুন:

**টার্মিনাল ১ (সার্ভার):**
```bash
cd server
npm run dev
# অথবা node src/server.js (পোর্ট ৫০৫০)
```

**টার্মিনাল ২ (ক্লায়েন্ট):**
```bash
cd client
npm run dev
# ভিজিট করুন http://localhost:5173
```

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend**: React 18, Vite, Vanilla CSS Design System, Lucide Icons, Axios
- **Backend**: Node.js, Express.js, Mongoose, CORS, Dotenv
- **Database**: MongoDB Atlas (স্মার্ট ইন-মেমোরি অফলাইন ফলব্যাক সহ)
- **APIs**: Quran.com API v4, AlQuran Cloud API
